# Playwright TypeScript E2E Automation Framework

End-to-end UI automation framework built using Playwright and TypeScript with Page Object Model, external test data, reusable page classes, assertions, and GitHub Actions CI/CD.

## Tech Stack

- Playwright
- TypeScript
- Page Object Model
- JSON Test Data
- Git & GitHub
- GitHub Actions

## Project Structure

- `pages/` - Page Object classes
- `tests/` - End-to-end test scenarios
- `data/` - Test data
- `.github/workflows/` - CI workflow
- `playwright.config.ts` - Playwright configuration
